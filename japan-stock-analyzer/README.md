# 日本株自動分析ツール 📈

日本株式市場を **毎朝・毎昼・毎夕の1日3回** 自動分析し、市場の流れ・投資候補銘柄・売買タイミング(買い / 利益確定 / 損切り)をレポートするツールです。

- **投資手法**: スイングトレード(1週間〜1ヶ月)+ 長期投資
- **リスク方針**: ミドルリスク・ミドルリターン(流動性・ボラティリティのフィルタで極端な銘柄を除外)
- **実行基盤**: GitHub Actions(サーバー不要・無料枠で運用可能)

## 何をしてくれるか

1日3回(平日のみ)、以下を自動実行してMarkdownレポートを生成し、リポジトリにコミットします。

| 時刻 (JST) | セッション | 内容 | 通知 |
|---|---|---|---|
| 8:30 | 朝(寄り前) | 前日の米国市場・為替を踏まえた寄り付き前の分析 | ✅ |
| 12:30 | 昼(前場終了後) | 前場までの動きの確認と後場に向けたスタンス | ✅ |
| 16:30 | 夕(大引け後) | 本日の総括・スクリーニング・ウォッチリスト見直し | - |

### 通知

朝・昼の分析結果サマリー(市況・買いシグナル・売買プラン・月次進捗)は、リポジトリの **GitHub Issue「📈 日本株分析通知 YYYY-MM」にコメント**として投稿され、オーナーが@メンションされます。GitHubの通知設定に応じてメール・スマホアプリのプッシュで受け取れます(GitHubモバイルアプリのインストール推奨)。

さらに、リポジトリの **Settings → Secrets and variables → Actions** に以下のSecretを登録すると、対応するサービスにも同じ内容が届きます(複数併用可・登録したものだけ有効)。

| サービス | 必要なSecret | 取得方法 |
|---|---|---|
| Discord | `DISCORD_WEBHOOK_URL` | サーバー設定 → 連携サービス → ウェブフック → 新しいウェブフック → URLをコピー |
| Slack | `SLACK_WEBHOOK_URL` | Slack API で Incoming Webhook を作成 |
| LINE | `LINE_CHANNEL_ACCESS_TOKEN` と `LINE_USER_ID` | [LINE Developers](https://developers.line.biz/)でMessaging APIチャネルを作成 → チャネルアクセストークン(長期)を発行。`LINE_USER_ID` はチャネル作成後の「あなたのユーザーID」(Basic settings内)。作成したBot(公式アカウント)を自分のLINEで友だち追加しておく。無料枠は月200通(本ツールは月44通程度) |
| Telegram | `TELEGRAM_BOT_TOKEN` と `TELEGRAM_CHAT_ID` | @BotFather でBot作成→トークン取得。Botに何かメッセージを送った後 `https://api.telegram.org/bot<トークン>/getUpdates` で自分のchat idを確認 |

※ LINE Notify は2025年3月にサービス終了したため、公式のMessaging APIを使用しています。通知するセッションは `config.yaml` の `notify.sessions` で変更できます。

### 月次目標

`config.yaml` の `targets.monthly` で月ごとの運用資金と利益目標を管理します(いつでも編集可)。

- 運用資金から1銘柄あたりの予算を自動算出(既定: 資金÷2銘柄)
- 資金が小さい月は**単元未満株(楽天かぶミニ/SBI S株)前提の1株単位**で株数を提案
- レポートと通知に「今月の損益・達成率・残り営業日・必要ペース」を毎回表示

### 各回の分析内容

1. **市況分析(市場の流れ)** — 日経平均・TOPIX・グロース・ドル円・米国株(S&P500 / NASDAQ / SOX)・VIX・米10年債利回り・WTI原油を分析し、「リスクオン〜リスクオフ」の総合判断とその日の戦い方を提示
2. **セクターローテーション分析** — セクター別モメンタム+マクロ経済要因(円相場→輸出/内需、原油→エネルギー/運輸、**国内金利(日本10年債)→金融**(利上げ局面は銀行株の買い材料として重み2で加点)、米金利→金融/不動産、VIX→ディフェンシブ、SOX→半導体)で「上昇見込みセクター」を判定し、該当セクターの銘柄に加点。下落見込みセクターの銘柄は新規候補から除外
3. **銘柄スクリーニング** — 東証主力約105銘柄(`data/universe.json`、編集可)をテクニカル100点満点+セクター加点で採点
   - トレンドフォロー: トレンド(30点)/ モメンタム(20点)/ ボラティリティ適性(15点)/ 押し目(15点)/ 出来高(10点)/ 52週レンジ位置(10点)
   - **大型株に厳選**: 時価総額5,000億円以上 + セクター内売買代金上位3銘柄のみ
   - **財務健全性**: 自己資本比率40%以上(Yahoo Financeの貸借対照表から算出。銀行等は業態上比率が低いため金融セクターは適用除外)
   - 流動性(売買代金1億円/日以上)・価格帯・ATR%(1.0〜4.5%)のハードフィルタ = **ミドルリスク条件**
4. **買いタイミングの検出** — 3種類のシグナル
   - 押し目買い(上昇トレンド中の25日線近辺への押しからの反発)
   - ブレイクアウト(60日高値を出来高増を伴い更新)
   - ゴールデンクロス(5日線が25日線を上抜け)
5. **売りタイミングの算出** — 銘柄ごとに具体的な価格を提示
   - **利益確定**: エントリー + 2.5 × ATR(またはスイング +12% 目安)
   - **損切り**: 直近安値 or エントリー − 1.5 × ATR(最大 −8% でキャップ)
   - **長期保有の撤退ライン**: 終値が75日線を明確に割れたら売り
   - リスクリワード比 1.5 未満のシグナルは「見送り推奨」と明示
6. **ウォッチリスト(継続観察)** — 候補銘柄を SQLite DB(`data/watchlist.db`)に保存して毎回再評価
   - スコア45点未満(またはフィルタ落ち)が **3回連続** → 自動削除
   - **60日** 観察してシグナル不発 → 自動削除
   - 最大20銘柄まで保持
7. **発注案の生成** — 買いシグナル銘柄について、予算(既定30万円/銘柄)内の株数・注文方法・利確指値・損切り逆指値の注文案を出力

## 自動売買について(重要)

**楽天証券・SBI証券には、個人が使える公式の発注APIが存在しないため、実口座への自動発注は実装していません**(非公式なスクレイピング発注は規約違反・口座凍結リスクがあるため行いません)。

代わりに以下の2段構えです。

1. **ペーパートレード(実装済み・既定で有効)** — 買いシグナルに従って仮想売買を自動執行します。損切り・利確・75日線割れ・保有期間上限(45日)による決済も全自動で、資産推移・実現損益・勝率をDBで管理し毎回のレポートに表示します。`config.yaml` の `trading.mode: off` で停止できます。初期資金・予算・同時保有数も同ファイルで変更可能です。
2. **発注案の自動生成** — 実際に売買する場合は、レポートの発注案(株数・利確指値・損切り逆指値入り)を証券アプリからそのまま手動発注する運用を想定しています。

実口座での自動発注をどうしても実現したい場合の選択肢:

| 方法 | 概要 | 注意点 |
|---|---|---|
| 楽天証券 MarketSpeed II RSS | Excel経由で発注可能な公式機能 | Windows + Excel 必須。常時起動PCが必要 |
| auカブコム証券 kabu STATION API | 個人向け公式REST API | 証券口座の追加開設が必要 |
| 立花証券 e支店 API | 個人向け公式API | 同上 |

非公式なスクレイピングによる自動発注は、規約違反・口座凍結リスクがあるため実装していません。

## セットアップ

リポジトリを GitHub に push するだけで、`.github/workflows/stock-analysis.yml` のスケジュールに従って自動実行が始まります(リポジトリの Actions が有効になっていることを確認してください)。

手動実行: GitHub の Actions タブ →「日本株自動分析(朝・昼・夕)」→ Run workflow

### ローカルで実行する場合

```bash
cd japan-stock-analyzer
pip install -r requirements.txt
python run_analysis.py                    # JST時刻からセッション自動判定
python run_analysis.py --session evening  # セッション明示指定
JSA_MOCK=1 python run_analysis.py         # 合成データで動作テスト(オフライン可)
```

レポートは `reports/YYYY-MM-DD/{morning,noon,evening}.md` に出力され、最新版は `reports/latest.md` からいつでも参照できます。

## カスタマイズ

- **`config.yaml`** — スコア閾値・利確/損切り幅・観察期間・1銘柄あたり予算などすべて調整可能
- **`data/universe.json`** — スクリーニング対象銘柄の追加・削除(証券コードと銘柄名を書くだけ)

## 構成

```
japan-stock-analyzer/
├── run_analysis.py        # エントリーポイント
├── config.yaml            # 戦略パラメータ
├── analyzer/
│   ├── data.py            # 株価データ取得(yfinance)
│   ├── indicators.py      # テクニカル指標(SMA/RSI/MACD/ATRなど)
│   ├── market.py          # 市況分析(リスクオン/オフ判定)
│   ├── screener.py        # ユニバースのスクリーニング
│   ├── signals.py         # スコアリング・買いシグナル・売買プラン算出
│   ├── watchlist.py       # ウォッチリストDB(SQLite)と観察・削除ロジック
│   └── report.py          # Markdownレポート生成
├── data/
│   ├── universe.json      # スクリーニング対象銘柄
│   └── watchlist.db       # ウォッチリストDB(自動生成・自動コミット)
└── reports/               # 分析レポート(自動生成・自動コミット)
```

## データソース

すべて無料・APIキー不要で動作します。

| ソース | 用途 | 備考 |
|---|---|---|
| Yahoo Finance (yfinance) | 株価・指数・為替・PER/配当(主データソース) | 無料・キー不要。日本株は`XXXX.T` |
| Stooq | 株価・主要指数のフォールバック+日本10年国債利回り | 無料CSV API。Yahoo障害時に自動で切替 |

さらに精度を上げたい場合は、東証公式の **J-Quants API**(無料プランあり。ただし無料プランは12週遅延データ)への差し替えも可能な構成にしています。
